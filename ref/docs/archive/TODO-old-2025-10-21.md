## 🎯 RESEARCH: Teamtailor Integration (Oct 19, 2025)

### Opportunity Analysis
**Current State:**
- 2.4% of our jobs (8/334) use Teamtailor
- 30% of LinkedIn jobs use Teamtailor (user observation)
- Teamtailor has PUBLIC API for fetching questions AND submitting applications
- No account required for applicants

**API Capabilities:**
- ✅ GET /inquiry - Fetch application questions
- ✅ POST /apply - Submit complete application
- ✅ Supports 8 question types: text, textarea, select, multiselect, range, file, date, number
- ✅ Conditional questions supported

### Implementation Roadmap

**Phase 1: Detection (Week 1-2)**
- [ ] Build HTML fingerprinting system
  - Check for: data-teamtailor, teamtailor.com/assets, __TEAMTAILOR_CAREER_SITE__
  - Test with 8 existing Teamtailor jobs
- [ ] Add "🎯 Teamtailor Application" badge to job cards
- [ ] Build known domains database (hybrid approach)

**Phase 2: Question Preview (Week 3-4)**
- [ ] Integrate GET /inquiry endpoint
- [ ] Parse and display questions in modal
- [ ] Show question types and requirements
- [ ] Manual answer entry (copy/paste workflow)

**Phase 3: AI Answer Generation (Week 5-6)**
- [ ] Extend Application Assistant for competence questions
- [ ] Generate answers based on CV + job description
- [ ] Show confidence scores and warnings
- [ ] Allow editing before submission

**Phase 4: Direct Apply (Month 3+ - Requires Partnership)**
- [ ] Contact Teamtailor about Job Board partnership
- [ ] Get JobBoardId credentials and API access
- [ ] Integrate POST /apply endpoint
- [ ] Build one-click apply feature
- [ ] Handle validation and errors

### Technical Challenges
- **Detection:** Can't rely on URL alone (companies use custom domains)

### Expected Impact
- Save users 10-15 min per Teamtailor application
- Unique competitive advantage (no competitors do this)
- Potential premium feature
- Impact grows significantly if we add LinkedIn connector

### Next Steps
1. Build Phase 1 (detection) and validate with users

3. If high usage → Pursue Teamtailor partnership for Phase 4

## 🇸🇪 RESEARCH: Swedish Job Boards (Oct 19, 2025)

### Critical Discovery: Blocket Jobb Closed!
**Blocket Jobb shut down December 2024** - This changes the Swedish market landscape.

### Current Swedish Job Board Landscape

**Tier 1: Already Have** ✅
- Arbetsförmedlingen: 50,000+ jobs (government) - ✅ **Have connector**
- LinkedIn: 100,000+ jobs (90% of companies) - ❌ Need partnership
- Indeed: 80,000+ jobs (60% of companies) - ❌ Need connector

**Tier 2: Job Aggregators (Filling Blocket's Gap)**
- **JobbLand**: 84,638 jobs - ⚠️ **Aggregator** (pulls from AF + others)
- **LedigaJobb**: 70,745 jobs - ⚠️ **Aggregator** (pulls from AF + others)
- **JobsinStockholm**: 14,000+ jobs - English speakers, tech-heavy

**Tier 3: Specialized Swedish Boards**
- **Academic Work**: 5,000+ jobs - Students/young professionals
- **The Hub**: 3,000+ jobs - Tech/startups
- **StudentJob**: 2,000+ jobs - Students/part-time
- **Metrojobb**: 3,000+ jobs - Stockholm region

### Key Insight: Aggregator Problem ⚠️

**JobbLand and LedigaJobb are aggregators, NOT original sources!**

They pull jobs from:
- Arbetsförmedlingen (which we already have)
- LinkedIn (which we don't have)
- Indeed (which we don't have)
- Company websites

Building connectors for them would give us:
- ✅ 80k+ jobs total
- ❌ But 70-80% duplicates with our Arbetsförmedlingen connector
- ❌ We'd be aggregating aggregators (data quality issues)

### Revised Recommendation: Focus on Original Sources

**Priority 1: Indeed Sweden** 🟢 **HIGH PRIORITY**
- 80,000+ jobs
- Original source (not aggregator)
- Has Publisher API (available)
- Easy partnership process
- Would fill most of the gap left by Blocket

**Priority 2: JobsinStockholm** 🟡 **MEDIUM PRIORITY**
- 14,000+ jobs
- International/English speakers
- Tech-focused (matches our audience)
- Part of global network

**Priority 3: Academic Work** 🟡 **MEDIUM PRIORITY**
- 5,000+ jobs
- Perfect demographic (young professionals)
- Entry-level roles
- Original source

**Priority 4: The Hub** 🟡 **MEDIUM PRIORITY**
- 3,000+ tech/startup jobs
- High quality roles
- Original source

**NOT RECOMMENDED:**
- ❌ JobbLand (aggregator - 80% overlap with AF)
- ❌ LedigaJobb (aggregator - 80% overlap with AF)

## 🏢 RESEARCH: Should LazyJobs Build an ATS? (Oct 19, 2025)

### Strategic Question
**Current:** LazyJobs = B2C (job seekers)  
**Potential:** LazyJobs = B2B (companies) + B2C (job seekers)

### What Teamtailor Does
1. Companies create jobs in ATS ($200-2000/month)
2. Teamtailor distributes to LinkedIn, Indeed, Arbetsförmedlingen, etc.
3. Applications flow back to ATS
4. Companies manage hiring process
5. Revenue: €5,000-€30,000/year per customer

### Build Difficulty: **6-12 months, 2-3 developers**

**Core ATS Features (Must Have):**
- [ ] Job posting creation/management
- [ ] Application form builder (questions, file uploads)
- [ ] Candidate database
- [ ] Application pipeline (stages: Applied → Interview → Offer → Hired)
- [ ] Email templates and automation
- [ ] Team collaboration (comments, ratings)
- [ ] Reporting and analytics

**Distribution Features (High Value):**
- [ ] LinkedIn integration (job posting)
- [ ] Indeed integration
- [ ] Arbetsförmedlingen integration
- [ ] Custom career site (hosted)
- [ ] Job board API/XML feeds

**Advanced Features (Competitive):**
- [ ] Video interview scheduling
- [ ] AI candidate screening
- [ ] Automated email sequences
- [ ] Calendar integrations
- [ ] GDPR compliance tools
- [ ] Multi-language support

### Market Analysis

**Competitors:**
- Teamtailor (Sweden) - €200-2000/month
- Greenhouse (US) - $500-1000/month
- Lever (US) - $400-800/month
- Workable (Global) - €99-399/month
- Recruitee (EU) - €199-599/month

**Market Size:**
- Global ATS market: $2.3B (2024)
- Growing 7% annually
- 100,000+ companies use ATS globally

### Build vs. Partner Decision

**Option A: Build Our Own ATS** 🏗️
**Pros:**
- ✅ Full control over features
- ✅ Keep 100% of revenue
- ✅ Unique integration with LazyJobs
- ✅ Can innovate faster

**Cons:**
- ❌ 6-12 months development time
- ❌ Need 2-3 additional developers
- ❌ High complexity (compliance, security, etc.)
- ❌ Competing with established players
- ❌ Need sales team for B2B
- ❌ Different business model (B2B vs B2C)

**Option B: Partner with Existing ATS** 🤝
**Pros:**
- ✅ Fast to market (1-2 months)
- ✅ Leverage existing features
- ✅ Focus on core product (LazyJobs)
- ✅ Revenue share possible

**Cons:**
- ❌ Less control
- ❌ Revenue sharing
- ❌ Dependent on partner

**Option C: Hybrid (LazyJobs as Job Board)** 🎯
**Pros:**
- ✅ Simpler than full ATS
- ✅ Companies post jobs directly
- ✅ We handle distribution to job seekers
- ✅ No hiring process management
- ✅ 2-3 months development

**Cons:**
- ❌ Lower revenue per customer
- ❌ Still need sales/marketing
- ❌ Competing with LinkedIn, Indeed

### Recommendation: **Option C (Hybrid) - Long Term**

**Why:**
1. **Simpler scope:** Just job posting, not full hiring process
2. **Unique value:** Direct access to LazyJobs users
3. **Two-sided marketplace:** Companies pay to post, users apply for free
4. **Faster to build:** 2-3 months vs 12 months
5. **Synergy:** Companies want visibility, we have engaged users

**Pricing Model:**
- Free: 1 job posting
- Basic: €99/month - 5 active jobs
- Pro: €299/month - Unlimited jobs + featured placement
- Enterprise: Custom - API access, analytics, priority support

**Revenue Potential:**
- 100 companies × €99/month = €9,900/month
- 1000 companies × €150/month avg = €150,000/month

### Implementation Timeline (If Pursued)

**Phase 1: Research (Month 1)**
- [ ] Survey companies: Would they pay to post on LazyJobs?
- [ ] Validate pricing with 10-20 companies
- [ ] Analyze competitor features
- [ ] Calculate development cost

**Phase 2: MVP (Month 2-4)**
- [ ] Company signup and authentication

**Phase 4: Scale (Month 7+)**
- [ ] API for programmatic posting
- [ ] Integration with existing ATS systems
- [ ] Advanced analytics
- [ ] Team accounts

### Decision Criteria

**Build ATS/Job Board if:**
- ✅ LazyJobs has 10,000+ active users
- ✅ 50+ companies express interest
- ✅ Can hire 2 additional developers
- ✅ Have 6-12 months runway
- ✅ Want to pivot to B2B revenue

**Don't build if:**
- ❌ Focus should be on core product
- ❌ User growth is priority
- ❌ Limited development resources
- ❌ Prefer B2C model

**Focus on:**
